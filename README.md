# TASKFLOW - Görev Yönetim Sistemi API

Bu proje, Node.js ve Express.js kullanılarak geliştirilmiş bir REST API'dir.

## Kurulum Adımları
1. Proje dosyalarını bilgisayarınıza indirin.
2. Terminali açın ve proje klasörünün içine girin.
3. Gerekli kütüphaneleri kurmak için şu komutu çalıştırın:
   `npm install`

## Projeyi Çalıştırma
1. Kurulum bittikten sonra sunucuyu başlatmak için şu komutu çalıştırın:
   `node server.js`
2. Sunucu başarıyla çalıştığında terminalde `http://localhost:3000 adresinde çalışıyor` mesajını göreceksiniz.
3. Postman kullanarak `http://localhost:3000/api/tasks` adresine HTTP istekleri (GET, POST, PUT, DELETE) atabilirsiniz.
